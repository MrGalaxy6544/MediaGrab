# MediaGrab

หน้าเว็บ Static สำหรับตรวจสอบและเปิดลิงก์วิดีโอหรือสตรีมที่ผู้ใช้มีสิทธิ์เข้าถึง สร้างด้วย HTML, Tailwind CSS และ JavaScript โดยไม่ต้องมี backend

## ใช้งาน

1. เปิด `index.html` ในเบราว์เซอร์ หรือเผยแพร่ไฟล์นี้ด้วย GitHub Pages
2. วาง URL สื่อโดยตรงที่รองรับ HTTP/HTTPS แล้วเลือก **เปิดสื่อ**
3. หากต้นทางอนุญาต เบราว์เซอร์จะแสดงตัวเล่นและลิงก์ดาวน์โหลด

## GitHub Pages

1. ไปที่ **Settings → Pages** ของ repository
2. เลือก branch ที่ต้องการ และโฟลเดอร์ `/ (root)` แล้วกด **Save**
3. รอให้ GitHub Pages เผยแพร่เว็บไซต์

## ข้อจำกัดและความเป็นส่วนตัว

- เว็บไซต์ต้นทางอาจบล็อกการฝังสื่อหรือการเข้าถึงข้ามโดเมนด้วย CORS; หน้าเว็บนี้ไม่สามารถข้ามข้อจำกัดดังกล่าวได้
- การเปิดหรือดาวน์โหลดขึ้นกับชนิดไฟล์ การตั้งค่าของเบราว์เซอร์ และสิทธิ์ที่ผู้ให้บริการต้นทางกำหนด
- ใช้กับเนื้อหาที่คุณเป็นเจ้าของหรือได้รับอนุญาตเท่านั้น และปฏิบัติตามกฎหมายลิขสิทธิ์กับข้อกำหนดของบริการต้นทาง
- หน้าเว็บโหลด Tailwind CSS และฟอนต์จาก CDN ภายนอก; ไม่มี backend และไม่มีการเก็บข้อมูลบนเซิร์ฟเวอร์
