ประวัติ

      
เก็บในเบราว์เซอร์นี้เท่านั้น ลิงก์ไฟล์จาก CDN มักหมดอายุ จึงต้องกด "ดึงอีกครั้ง" ก่อนดาวน์โหลด

    

    
  

  







  

    

      
cobalt API (สำหรับ Instagram, Facebook, X, YouTube ฯลฯ)

      
GitHub Pages เป็นเว็บ static ดึงวิดีโอจาก IG/FB เองไม่ได้ ต้องมีเซิร์ฟเวอร์ cobalt ของคุณเอง (ดู README) อินสแตนซ์สาธารณะอย่าง api.cobalt.tools ไม่อนุญาตให้เว็บอื่นเรียกใช้ ต้องเป็น HTTPS เท่านั้น

    

    

      

        
        
      

      

        
        
      

      

        
        
      

      

    


    

      
CORS Proxy (ไม่บังคับ แต่แนะนำ)

      
ใช้ Cloudflare Worker ในไฟล์ worker.js ช่วยดึงไฟล์จากเซิร์ฟเวอร์ที่บล็อก CORS (เช่น CDN ของ TikTok หรือสตรีม HLS บางเจ้า) และส่ง Referer ให้
